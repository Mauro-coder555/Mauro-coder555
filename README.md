## 🚀 Top 5 proyectos

### 1. 🖼️ People Image Dataset Builder  
<a href="https://github.com/Mauro-coder555/google-images-people-dataset" target="_blank" rel="noopener">Repositorio</a>

Aplicación de escritorio en **Java** para construir datasets de imágenes de personas a partir de búsquedas automatizadas en Google Images.

Permite cargar personas desde un JSON, buscar imágenes por nombre y sinónimos, descargar resultados, generar metadata y empaquetar el dataset final en `.tar.gz`.

**Tecnologías:** Java 21, Maven, Selenium WebDriver, Java Swing, Gson, Apache Tika, Apache Commons, SLF4J.

---

### 2. 🛠️ IT Evidence Collector  
<a href="https://github.com/Mauro-coder555/it-evidence-collector" target="_blank" rel="noopener">Repositorio</a>

Herramienta local para soporte técnico en Windows. Recolecta evidencia básica del equipo en modo solo lectura y genera reportes Markdown para facilitar el diagnóstico inicial.

**Tecnologías:** Python, Tkinter, Windows Events, Markdown.

---

### 3. 📁 Folder Organizer  
<a href="https://github.com/Mauro-coder555/folder-organizer" target="_blank" rel="noopener">Repositorio</a>

Aplicación local para ordenar carpetas desorganizadas de forma simple y segura. Analiza archivos, propone una clasificación automática y muestra una vista previa antes de moverlos.

**Tecnologías:** Python, Tkinter, pathlib, shutil, JSON, unittest.

---

### 4. 📚 Support Knowledge Finder  
<a href="https://github.com/Mauro-coder555/support-knowledge-finder" target="_blank" rel="noopener">Repositorio</a>

Aplicación para registrar problemas de soporte, buscar casos similares y generar runbooks en Markdown a partir de soluciones verificadas.

**Tecnologías:** Python, Streamlit, SQLite, Markdown.

---

### 5. 🎮 Steam Recommendation System  
<a href="https://github.com/Mauro-coder555/Steam-Rec-System" target="_blank" rel="noopener">Repositorio</a>

Sistema de recomendación basado en datos de Steam. Incluye procesos de ETL, análisis de datos, consultas útiles, modelado y despliegue de una API.

**Tecnologías:** Python, Pandas, ETL, Machine Learning, FastAPI, Render, NLP.
